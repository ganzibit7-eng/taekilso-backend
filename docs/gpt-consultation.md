# GPT 우선 상담 — 2026-11-18

일반 상담과 새로 생성하는 신년 리포트는 서버 설정 `AI_PRIMARY_PROVIDER=openai`, `OPENAI_MODEL=gpt-6.2-sol`에서 GPT를 우선 사용한다. 연결 실패·시간 초과·429·서버 오류·인증 오류에만 같은 입력과 검증 경로로 기존 Claude에 한 번 전환한다. 정상 GPT 응답에는 Claude를 호출하지 않는다. 사용자 본문은 제공사나 모델을 바꿀 수 없다.

근거 불일치는 같은 제공사에서 기존의 한 차례 보정 절차를 거친다. 검증 실패·거절·불완전 응답·잘못된 요청 형식은 Claude로 우회하지 않는다. 두 제공사가 모두 실패하면 이용권 차감을 복원하는 기존 절차를 유지한다. 확장된 채팅은 생성/보정 단계당 총 65초(GPT 40초 후 장애 복구 여유), 직접 Claude 경로는 45초 이내다. 신년은 기존 150초 요청과 전체 160초 보정 예산을 유지한다.

새 프롬프트 `taekilso-grounded-1.16.0`은 공통 규칙, 현재 주제의 모듈, 선택한 출력 규칙만 조합한다. 원국에서 방법과 근거가 기록된 해석 판정 → 쉬운 생활어 → 현재 고민에 적용할 조건 → 선택별 장단점과 첫 행동을 연결한다. 짧은 개념 질문에는 억지 선택지를 붙이지 않는다. 실제 소비처·상대 마음·미래 사건을 지어내지 않는다. 현재 상담사의 해요체·지역 어미와 서버의 말투 보정기를 그대로 사용한다.

분량은 일반 개인 상담 약 1,200~1,800자, 상세 요청 1,800~2,400자, 같은 주제의 후속 질문 700~1,100자를 목표로 한다. 짧게 요청하면 250~500자, 단순 개념은 400~700자를 목표로 한다. 실제 생성의 목표이며 글자수에 맞추려고 잘라내거나 부족분을 임의 문장으로 채우지 않는다. 일반/상세 본문은 서로 다른 요점의 3~4개 블록으로 쓰며 선택 방안은 별도다. 근거가 부족하거나 답을 제한할 때는 분량을 강제하지 않는다. 채팅 출력 상한은 2,400에서 4,800토큰으로 확대하고 추가 요약 호출 없이 같은 한 번의 생성에서 내용을 충분히 설명한다. 신년 리포트의 기존 분량과 출력 상한은 유지한다.

비용은 API가 반환한 입력/출력·캐시 읽기/쓰기 토큰을 분리해 공개 표준 단가로 산출한다. reasoning 토큰은 출력에 이미 포함되므로 다시 더하지 않는다. GPT 표준 단가는 입력 $2, 캐시 읽기 $0.1, 기본 캐시 쓰기 $2.5, 출력 $10/백만 토큰이다. 캐시 세부값 제공 여부를 기록한다. 두 번 호출해 보정했다면 모두 합치고, 통신 실패로 사용량을 받지 못한 호출은 0원으로 표시하지 않는다. 원화 환산·크레딧·세금·Cloud Run·Firestore 비용은 API 토큰 금액과 별도이며 실제 청구서를 대신하지 않는다.

계산 결과/후보 정책, 인물·후보별 근거 결합, 무료 리포트, 로그인, 무료 3질문, 프리미엄 하루 10질문, 기존 질문권, 신년 이용권·보관 리포트·결제·환불 로직은 변경하지 않는다. 기존 작성 완료 신년 리포트를 자동 재생성하지 않는다. 신규 결제의 운영 중지 상태도 유지한다. 관리자 전용 과거 프롬프트 비교 기능의 명시적인 `legacy` 요청은 기존 비교 경로다.

OpenAI 요청은 Responses API의 강제 함수 호출과 strict 스키마, low reasoning, `store:false`를 사용한다. 보정에 필요한 암호화 reasoning과 함수 결과는 그 요청의 메모리에만 보관한다. `store:false`는 별도 무보관 계약을 의미하지 않는다. 새로운 호출 기록에는 제공사·모델·시간·토큰·비용 추정만 추가하며 API 키나 질문 본문을 새로 기록하지 않는다. 기존 회원이 저장하는 상담 기록의 동작은 같다.
